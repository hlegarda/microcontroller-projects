# Arduino & ESP32 Projects

A collection of embedded systems projects built with Arduino and ESP32 microcontrollers, developed and managed using PlatformIO.

## Overview

This repository contains multiple independent projects exploring various microcontroller applications and sensor integrations. Each project is self-contained with its own configuration and source code.

## Technology Stack

- **Microcontrollers**: Arduino (various boards) and ESP32
- **Build System**: PlatformIO
- **Language**: C/C++

## Getting Started

Each project directory contains its own `platformio.ini` configuration file with board and environment specifications. To work with a specific project:

1. Open the desired project folder in your IDE
2. Review the `platformio.ini` for board and library configurations
3. Check the `src/main.cpp` for the project implementation
4. Build and upload using PlatformIO commands

## Project Structure

All projects follow a standard PlatformIO structure:
- `src/` - Main project source code
- `include/` - Header files
- `lib/` - Project-specific libraries
- `platformio.ini` - Project configuration
